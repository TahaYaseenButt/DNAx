\section{Software Modules}

\subsection{1. DNAx Signet (Bioinformatic Design Suite)}
Used for designing synthetic DNA sequences and assay parameters:
\begin{itemize}
    \item Generates sequence constructs with specified lengths and GC content.
    \item Calculates melting temperatures ($T_m$) for primers and probes.
    \item Screens sequences against standard databases to ensure specificity.
    \item Exports design specifications and associated QR codes.
\end{itemize}

\subsection{2. DNAx Manufacture (Product Integration \& Taggant Blending)}
DNAx Manufacture is designed to integrate the DNA taggant directly with the product:
\begin{itemize}
    \item \textbf{Product Integration}: Integrates the taggant with the physical product.
    \item \textbf{Automated Combinations}: Automates the combination of taggants from all available taggants while maintaining anonymity across the entire tagging process.
    \item \textbf{Data Association}: Saves all data regarding the specific combination of taggants against each unique barcode.
    \item \textbf{Development Status}: This feature is currently in the development phase, with active R\&D underway to complete it end-to-end.
\end{itemize}

\subsection{3. DNAx Inventory (Inventory Management)}
Desktop module for managing inventory:
\begin{itemize}
    \item Generates and assigns identifiers to product batches.
    \item Integrates barcode scanning for logging stock intake and dispatch.
    \item Tracks inventory records in the database.
\end{itemize}

\subsection{4. DNAx Vendor (Distribution \& Verification)}
Mobile application for distribution checks:
\begin{itemize}
    \item Scans barcodes/QR codes to verify recorded batches.
    \item Logs product issuance and handover events.
\end{itemize}

\subsection{5. DNAx Forensics (Laboratory Verification)}
Specialized verification software for testing laboratories:
\begin{itemize}
    \item Matches sequence data and gel electrophoresis sizing (e.g., 200~bp).
    \item Records and verifies qPCR results against registered batch profiles.
\end{itemize}

\section{Conclusion}
This project successfully established the laboratory workflow for the indigenous DNA tagging system:
\begin{itemize}
    \item Design of the 200~bp synthetic DNA construct and primers.
    \item Enzymatic amplification via PCR and size confirmation on 2.0\% agarose gel.
    \item Formulation of the 1.0-Liter TE buffer taggant solution.
    \item Specific detection and verification across individual and multiplex real-time qPCR probe assays.
    \item Application and non-destructive swabbing recovery on packaging QR codes.
\end{itemize}
