\section{Introduction to DNA-Based Information Storage}
Deoxyribonucleic acid (DNA) offers unprecedented theoretical data storage density ($4.55 \times 10^{18}$ bytes/gram) and biochemical stability spanning millennia under appropriate physical shielding. In the DNAx ecosystem, synthetic DNA serves as an ultra-high-entropy physical security identifier. Rather than encoding raw text, the sequence is engineered to function as a multi-stage molecular signature, containing:
\begin{enumerate}
    \item \textbf{Conserved Flanking Primer Binding Sites}: Dedicated $20\text{ bp}$ forward and reverse primer sequences that enable targeted polymerase chain reaction (PCR) amplification from complex environmental matrices.
    \item \textbf{Internal Multiplex Optical Probe Channels}: Contiguous $24\text{ bp}$ target hybridization sequences recognized by fluorescently labeled dual-quenched TaqMan hydrolysis probes during real-time qPCR.
    \item \textbf{Randomized Orthogonal Spacer Segments}: In silico screened nucleotide blocks that prevent steric clash, eliminate secondary stem-loop structures, and guarantee zero homology with environmental or human genomes.
\end{enumerate}

    \item \textbf{Stage 1: Physical Sizing}: The user defines the target construct length (standard: $200\text{ bp}$, expandable up to $1000\text{ bp}$). The system dynamically calculates the physical constraints:
    \begin{equation}
        L_{\text{min}} = L_{\text{Fwd}} + L_{\text{Rev}} + \sum_{i=1}^{N_{\text{probes}}} L_{\text{probe}, i} + (N_{\text{probes}} + 1) \cdot L_{\text{spacer}}
    \end{equation}
    where $L_{\text{Fwd}} = 20\text{ bp}$, $L_{\text{Rev}} = 20\text{ bp}$, $L_{\text{probe}} = 24\text{ bp}$, and $L_{\text{spacer}} \ge 6\text{ bp}$.
    
    \item \textbf{Stage 2: De Novo DNA Sequence Synthesis}: An orthogonal sequence is algorithmically generated using a constrained Markov random generator with GC-windowing ($48.0\% \le \text{GC} \le 52.0\%$), zero homopolymer runs ($\ge 4$ identical consecutive nucleotides), and complete exclusion of major restriction enzyme recognition sites (e.g., \textit{EcoRI}, \textit{BamHI}, \textit{HindIII}, \textit{BsaI}).
    
    \item \textbf{Stage 3: In Silico Homology \& Local BLAST Screening}: The sequence is screened locally against the NCBI non-redundant nucleotide database and an internal matrix of all previously registered DNAx tags. Sequences exhibiting $\ge 75\%$ identity over any $20\text{ bp}$ window with pathogenic or common environmental microorganisms are automatically rejected to eliminate false positives and biosafety compliance issues.
    
    \item \textbf{Stage 4: PCR Primer Pair Generation}: Orthogonal forward and reverse primers are designed using SantaLucia nearest-neighbor thermodynamic parameters:
    \begin{equation}
        T_m = \frac{\Delta H^\circ}{\Delta S^\circ + R \ln(C_T / 4)} + 16.6 \log_{10}[\text{Na}^+]
    \end{equation}
    Primers are constrained to $L = 20\text{ bp}$, $T_m = 58.5 \pm 1.0^\circ\text{C}$, $\Delta T_m \le 0.5^\circ\text{C}$, and $\Delta G_{\text{3'-dimer}} > -2.0\text{ kcal/mol}$.
    
    \item \textbf{Stage 5: Multiplex qPCR Hydrolysis Probes}: The engine assigns up to 8 distinct hybridization target zones within the construct core. Probes are strictly standardized to $24\text{ bp}$ and $T_m \ge 68.0^\circ\text{C}$ (strictly $+10.0^\circ\text{C}$ above primers to ensure complete probe binding before primer extension). Probes are programmatically forbidden from having a $5'\text{-Guanine}$ to prevent instantaneous fluorescence quenching.
    
    \item \textbf{Stage 6: Review, Cryptographic QR Generation \& Database Vaulting}: The verified construct is signed with an immutable SHA-256 hash token (e.g., \texttt{DNAX-QR-8F39A1C4}), logged to the central database, and exported as a formal molecular specification dossier.
\end{enumerate}

\section{Mathematical Combinatorics of the 200~bp Sequence Space}
The diversity and unforgeability of the DNAx system stem from the vast combinatorial sequence space available in biological polymers.

\subsection{Raw Sequence Combinations}
For a linear DNA construct of length $N = 200\text{ base pairs}$, with 4 possible nucleotide choices ($\text{A, T, C, G}$) per position, the total possible unique sequence combinations $S_{\text{total}}$ is given by:
\begin{equation}
    S_{\text{total}} = 4^{200} = (2^2)^{200} = 2^{400} \approx 2.58 \times 10^{120}
\end{equation}
This number ($2.58 \times 10^{120}$) exceeds the total estimated number of atoms in the observable universe ($\approx 10^{80}$) by 40 orders of magnitude, rendering brute-force guessing or accidental environmental duplication physically impossible.

\subsection{Modular Building Block Library Combinations}
To enable rapid modular synthesis and cost-effective multiplex qPCR detection, DNAx employs a combinatorial building block strategy. In this architecture, constructs are assembled from a standardized library of pre-validated, orthogonal 24~bp probe blocks.

For a library of $M = 72$ unique, non-interfering DNA building blocks, choosing $k = 4$ distinct blocks per taggant (without replacement, where order is tracked or unordered multiplexing is applied) yields:
\begin{equation}
    C(M, k) = \binom{72}{4} = \frac{72!}{4!(72-4)!} = \frac{72 \times 71 \times 70 \times 69}{4 \times 3 \times 2 \times 1} = \frac{24,690,960}{24} = 1,028,790
\end{equation}
Thus, a compact physical library of only 72 synthesized probe blocks yields \textbf{over one million ($>1.028 \times 10^6$) mathematically unique, fully orthogonal industrial taggants}.
