\section{Overview of Wet-Lab Experimental Validation}
To prove the physical viability of the DNA tagging system, end-to-end wet-lab experiments were conducted at ASAB-NUST. The empirical validation conclusively demonstrated:
\begin{enumerate}
    \item Successful synthesis, high-yield PCR amplification, and electrophoretic purity of the 200~bp master DNA construct.
    \item Complete, simultaneous 4-probe multiplex detection during real-time qPCR thermal cycling with zero cross-channel optical interference.
    \item Robust signal amplification across all four fluorophore probes (FAM, HEX, Texas Red, Cy5) with quantification cycle ($C_q$) values well within the optimal forensic detection window.
\end{enumerate}

\begin{itemize}
    \item \textbf{Precise Molecular Size}: The amplified product migrated precisely alongside the 200~bp ladder band, confirming target construct fidelity.

    \item \textbf{Negative Control Integrity}: Lane 3 (No Template Control) remained completely clear, confirming zero reagent contamination.
\end{itemize}

\section{Mathematical Combinatorics \& Unforgeability}
The physical security of the DNAx system rests on rigorous mathematical combinatorial principles:
\begin{enumerate}
    \item \textbf{Sequence Space ($200\text{ bp}$)}:
    \begin{equation}
        S_{\text{total}} = 4^{200} = 2^{400} \approx \mathbf{2.58 \times 10^{120}}
    \end{equation}
    This sequence space exceeds the total estimated number of elementary particles in the observable universe ($\approx 10^{80}$), ensuring that no counterfeit entity can synthesize the same sequence by chance.
    
    \item \textbf{Modular Building Block Combinations}:
    Selecting $k = 4$ distinct probe blocks from a standardized physical library of $M = 72$ validated building blocks yields:
    \begin{equation}
        C(72, 4) = \binom{72}{4} = \frac{72 \times 71 \times 70 \times 69}{4 \times 3 \times 2 \times 1} = \mathbf{1,028,790\text{ unique codes}}
    \end{equation}
    This enables over \textbf{one million unique, non-interfering industrial taggants} using a compact physical primer/probe set.
\end{enumerate}
