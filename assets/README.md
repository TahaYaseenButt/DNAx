Place your logo image files here. The application looks for these files (in order):

- dnax.png
- dnax_logo.png
- logo.png
- logo.gif

Recommended: a 160 px wide PNG with a transparent background. If Pillow is installed the app will resize the image automatically.

If you don't add an image, the app shows the text "DNAₓ Lab" in the side menu.
